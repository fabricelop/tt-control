# TTiTTulares / TT Control — línea visual editorial

## Imágenes generadas
Estilo de referencia aprobado el 19-09-2026:

- Viñeta editorial ilustrada, no fotorrealista.
- Acabado de prensa/revista: dibujo limpio, contornos marcados, color plano o ligeramente texturizado.
- Personajes públicos reconocibles mediante caricatura moderada, sin buscar una fotografía sintética.
- Formato horizontal pensado para acompañar un tuit.
- Una noticia = una idea visual = un gag principal. Evitar sobrecargar con objetos, paneles o explicaciones.
- El remate elegido debe integrarse literalmente en la imagen cuando sea visualmente viable.
- Texto adicional mínimo; no inventar frases atribuibles a protagonistas.
- Se puede usar metáfora visual, exageración y elementos de viñeta (bocadillo, cartel, móvil, objeto simbólico).
- Mantener una pequeña firma visual TTiTTulares/TT Control de forma consistente.
- Referencia preferida: el lenguaje gráfico de las cuatro variantes Trump–Delcy generadas en el chat del proyecto; evitar el enfoque hiperrealista de la imagen «Del sancionador al negociador».

## Regla de texto dentro de la imagen
- La imagen NO debe reproducir el texto base ni el titular/noticia que ya irá escrito en el tuit.
- El único texto editorial principal que debe integrarse en la imagen es el remate A/B/C seleccionado, literalmente cuando sea viable.
- Se permiten rótulos ambientales mínimos si son parte natural del gag visual (por ejemplo, un cartel de lugar o una etiqueta breve), pero no deben resumir ni repetir la noticia.
